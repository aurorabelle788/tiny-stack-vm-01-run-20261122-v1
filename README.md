# tiny-stack-vm-01 v1 — a tiny stack virtual machine

Entry for the make.fun bounty [Build a tiny stack virtual machine, 22 November 2026](https://make.fun/bounty/tiny-stack-vm-01-run-20261122): one program, `main.ts`, runs all 40 instances of a set — 32-bit wrapping arithmetic, a 256-value stack, branches, calls, 256 words of memory, input/output, and all ten traps with their exact exit codes. A faithful port of the kit's reference VM; practice score 1,000,000 (the house baseline plain-vm 1.0.0 scores 670,000).
